Política de privacidad

Última actualización: 27 de octubre de 2026

FitHealth es una aplicación personal de uso privado. Esta política explica qué datos lee, para qué y cómo se protegen.

1. Datos a los que accede

Con tu autorización expresa a través de Google, FitHealth lee de la Google Health API, con permisos de solo lectura:

  • Actividad y ejercicio: pasos, calorías, minutos activos y sesiones de entrenamiento.
  • Sueño: duración y fases del sueño.
  • Métricas de salud: frecuencia cardíaca, frecuencia cardíaca en reposo, variabilidad de la frecuencia cardíaca y peso.

Además, guarda los datos que introduces manualmente en la propia app (por ejemplo, tu peso diario, entrenos o cómo te sientes).

2. Para qué se usan

Solo para mostrarte tus propias estadísticas: recuperación, entrenos, sueño, calorías, comparaciones y retos. FitHealth no usa los datos para publicidad, no crea perfiles para terceros y no los utiliza para entrenar modelos de inteligencia artificial.

3. Con quién se comparten

Con nadie. FitHealth no vende, alquila ni cede tus datos a terceros. El único acceso es el del propietario de la cuenta.

4. Dónde se guardan y cómo se protegen

  • Los datos se guardan en una base de datos privada de la aplicación, accesible solo para su propietario.
  • Las comunicaciones con Google usan conexiones cifradas (HTTPS) y el estándar OAuth 2.0.
  • Las credenciales de acceso se almacenan de forma privada y nunca se publican.

5. Uso de los datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

6. Cómo retirar el acceso y borrar los datos

  • Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
  • Al retirar el permiso, FitHealth deja de poder leer datos nuevos. Los datos ya guardados pueden borrarse por completo desde la propia aplicación o eliminando su base de datos.

7. Cambios

Si esta política cambia, se actualizará esta página y la fecha de arriba.
